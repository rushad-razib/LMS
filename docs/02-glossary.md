# Glossary

**Status:** Clarified (batches + teachers 2026-08-03)

| Term | Meaning |
|------|---------|
| **Academy** | AR Visionary Academy — single vendor |
| **Student** | `STUDENT` via public registration |
| **Teacher** | `TEACHER` account created by Admin; manages assigned batches |
| **Admin** | `ADMIN`; full back-office |
| **Trainer (marketing)** | Public profile on marketing site; may map to a Teacher user later |
| **Course** | Sellable product; can have many Batches |
| **Batch** | Cohort instance of a course (schedule, teachers, live links, batch materials) |
| **Enrollment** | Student purchased/owns a course; may be **unassigned** or assigned to a `batchId` |
| **Order / Purchase** | Commercial record that creates enrollment |
| **Batch assignment** | Admin links enrollment → batch; triggers student email |
| **Live session** | Dated class on a batch: schedule + pasted Google Meet / Zoom URL |
| **Live class link** | Meeting URL on a Live session (not a single field on Batch) |
| **Batch announcement** | Notice scoped to one batch (teacher or admin) |
| **Batch material** | File/resource uploaded for a batch by teacher/admin |
| **Admission** | Legacy admin-approval signup — superseded as access gate |
